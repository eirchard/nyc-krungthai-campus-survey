# NYC · Krungthai Campus Survey & Bank Import Preparation

ระบบของ **วิทยาลัยการอาชีพนครยะลา** สำหรับสำรวจความประสงค์ใช้งาน Krungthai Campus และจัดเตรียมไฟล์ผู้ใช้ตามแม่แบบ Excel ของธนาคารกรุงไทย

> สำคัญ: เครื่องมือนี้ **ไม่ใช่** แอป Krungthai Campus ของธนาคาร ไม่ใช่การสมัครบัญชีธนาคาร และไม่ได้เชื่อมกับระบบ API ภายในธนาคารโดยตรง เป็นเครื่องมือของสถานศึกษาสำหรับประสานงานเท่านั้น

## ขอบเขตของระบบ

- หน้าแบบสำรวจสำหรับครู/บุคลากร/นักเรียน/นักศึกษา: รหัสเชิญรายคน, ความประสงค์ (ต้องการ/ไม่แน่ใจ/ไม่ต้องการ), ฟีเจอร์ที่สนใจ, ข้อเสนอแนะ, การรับทราบความเป็นส่วนตัว และการยินยอมแยกต่างหากสำหรับการเตรียมข้อมูลประสานธนาคาร
- หน้า Admin: สถิติความประสงค์, สถิติฟีเจอร์, เปิด/ปิดรับคำตอบ, ข้อความประกาศความเป็นส่วนตัว, นำเข้า `.xlsx` หรือ `.csv`, ดู/แก้ไข Q–S/W เท่านั้น, ออก/สร้างรหัสเชิญใหม่, ส่งออก CSV A–W
- Google Sheets: ตาราง `Users_A_W` (23 คอลัมน์), `InviteCodes` (เก็บ hash), `SurveyResponses`, `Settings`
- Google Apps Script: ตรวจสอบรหัสเชิญ, ป้องกันการตอบซ้ำ, เก็บคำตอบ, ตรวจการเตรียมไฟล์ธนาคาร
- Cloudflare Worker: API proxy, ตรวจรหัสผ่านผู้ดูแล, จัดการ CORS origin แบบโดเมน (`https://<username>.github.io`) และเก็บ Google URL/รหัสลับ
- GitHub Pages: เก็บเฉพาะหน้าเว็บและโค้ดสาธารณะ ไม่เก็บข้อมูลส่วนบุคคลของผู้ใช้

## ความสอดคล้องกับไฟล์ต้นฉบับ

ใช้โครงสร้าง 23 คอลัมน์ **A–W** และหัวคอลัมน์จากไฟล์ `importUserV3_NoOfRecord(1).xlsx` ที่ได้รับในบทสนทนานี้โดยตรง ไม่มีการสลับหรือเปลี่ยนชื่อคอลัมน์:

| ช่วง | ความหมาย | การทำงานในระบบ |
|---|---|---|
| A–P | ID, Code, Campus, Email, Prefix, Names, Birth date, Gender, Type, Guardian, Degree, Study year | นำเข้า/รักษาตามต้นฉบับ ไม่แก้จากหน้าจัดการ |
| Q | Faculty id | ผู้ดูแลระบุหรือแก้ไขได้ ต้องครบก่อนส่งออกธนาคาร |
| R–S | Department id, Curriculum id | ผู้ดูแลระบุได้ หากไม่มีเว้นว่าง |
| T–V | Nationality, Citizen id, Passport id | นำเข้า/รักษาตามต้นฉบับ ไม่แสดงให้ผู้ตอบแบบสำรวจ |
| W | Status | ผู้ดูแลระบุ Active/Inactive ผู้ส่งออกต้อง Active |

ไฟล์ตัวอย่างที่แนบมี 3 แถวตัวอย่าง แต่ **ชุดโปรแกรมนี้ไม่คัดลอกตัวอย่างหรือรายชื่อใด ๆ จากไฟล์ที่อัปโหลด** มีเพียงแม่แบบเปล่า `templates/krungthai_user_template.xlsx` ที่มีหัวคอลัมน์เหมือนเดิมเท่านั้น

### เงื่อนไขส่งออก

ระบบส่งออกได้เฉพาะผู้ที่ 1) ตอบว่า “ต้องการใช้งาน” 2) เลือกยินยอมแยกต่างหากสำหรับการใช้ข้อมูลเพื่อประสานธนาคาร 3) มีรหัส Q และสถานะ W เป็น Active และ 4) ข้อมูลบังคับตามแม่แบบมีครบ จะแสดงรายการที่ไม่ผ่านเงื่อนไขเป็นข้อสังเกตให้ผู้ดูแลปรับปรุง

**สำคัญ:** ความสนใจใช้งาน ≠ ความยินยอมของธนาคาร ผู้รับผิดชอบต้องตรวจขั้นตอนของธนาคารและกฎหมายข้อมูลส่วนบุคคลก่อนส่งไฟล์จริง โดยเฉพาะผู้เรียนที่ยังเป็นผู้เยาว์

## วิธีติดตั้ง (Windows Git Bash)

อาศัย `node`, `git`, `gh`, `clasp`, `npx`/Wrangler และ `curl` ที่ติดตั้งและลงชื่อเข้าใช้แล้ว (เหมือนชุด V2 เดิม)

1. แตกไฟล์ ZIP แล้วเปิดโฟลเดอร์ที่มี `install.sh`
2. เปิด **Git Bash** ภายในโฟลเดอร์นั้น
3. พิมพ์:

   ```bash
   bash install.sh
   ```

4. ตัวติดตั้งจะถามชื่อ repo (ค่าเริ่มต้น `nyc-krungthai-campus-survey`), ชื่อ Worker (ค่าเริ่มต้น `nyc-krungthai-campus-api`) และรหัสผ่านผู้ดูแล 12+ อักษร
5. จะสร้าง Google Spreadsheet ใหม่พร้อม Apps Script ที่ผูกกับชีต แล้ว `clasp push` โค้ด
6. **Google อาจต้องให้คุณกด Deploy/Authorize ด้วยตัวเอง**: เปิด Apps Script Editor URL ที่แสดง, เลือก `Deploy → New deployment → Web app` → `Execute as: Me` → `Who has access: Anyone` (รวมผู้ไม่ลงชื่อเข้าใช้) → `Deploy` → `Authorize` → คัดลอก URL `/exec` กลับไปวาง
7. ตัวติดตั้งจะ **ตรวจ Backend JSON** ด้วยรหัสลับก่อนติดตั้ง Cloudflare ถ้าไม่พร้อมจะขอให้แก้ Deployment ก่อน ไม่สร้าง Worker แบบสุ่มไปเรื่อย ๆ
8. หลังตรวจผ่าน จะติดตั้ง Worker, เติม Secrets, ตรวจ `/health` และ `/api/config`, สร้าง GitHub Repository ใหม่และเผยแพร่ `main` + `/docs`
9. เปิด URL หน้า `admin.html`, นำเข้า Excel, เก็บไฟล์รหัสเชิญ CSV ไว้ในพื้นที่ส่วนตัว แล้วแจกให้แต่ละคนโดยช่องทางที่เหมาะสม
10. ทดลองตอบ 1 รายการ แล้วตรวจสถิติใน Admin ก่อนใช้จริง

### ติดตั้งซ้ำ / เมื่อ Google Web App ไม่พร้อม

ตัวติดตั้งบันทึกค่าเดิมใน `.local/setup.env`, URL เว็บแอปใน `.local/gas_url`, และ `.clasp.json` ใน `private/gas-work` โดยไม่เพิ่มไฟล์เหล่านี้เข้า GitHub การรัน `bash install.sh` อีกครั้งจะใช้ **โปรเจกต์และรหัสลับเดิม** ไม่สุ่มรหัสใหม่

หากแก้โค้ด Apps Script ภายหลัง ต้องเข้า `Deploy → Manage deployments → Edit → Version: New version` เพื่อเผยแพร่โค้ดล่าสุด มิฉะนั้น URL `/exec` อาจยังใช้โค้ดเวอร์ชันเก่า

## วิธีใช้งาน Admin

1. **นำเข้า Excel**: เลือกไฟล์ `.xlsx`/`.csv` ต้นฉบับ โปรแกรมจะตรวจ 23 หัวคอลัมน์ A–W และส่งเป็นชุดละ 50 รายการ
2. **ดาวน์โหลดรหัสเชิญ**: ระบบสร้างรหัส 28 อักขระแบบสุ่ม; ใน Google Sheets จะเก็บเฉพาะ SHA-256 ของรหัส เมื่อปิดหน้าจอจะไม่ดูรหัสเก่าได้อีก สามารถสร้างใหม่เฉพาะคนที่ยังไม่ตอบ
3. **ข้อมูล Q–S/W**: แก้ได้เฉพาะคอลัมน์เหล่านี้ หน้า Admin ไม่แก้ A–P/T–V
4. **แดชบอร์ด**: ดูความสนใจและร้อยละการตอบแบบสำรวจ (ไม่แสดงชื่อ/เลขบัตรในแดชบอร์ด)
5. **ส่งออกธนาคาร**: ผู้ดูแลต้องเปิดสิทธิ์ “อนุญาตให้เตรียมไฟล์ส่งให้ธนาคาร” หลังได้รับอนุมัติ จึงจะดาวน์โหลด CSV A–W ตามแม่แบบได้

## ข้อควรระวังด้านความปลอดภัย

- ต้องกำหนดคำประกาศความเป็นส่วนตัว ผู้รับผิดชอบข้อมูล จุดติดต่อ และระยะเวลาเก็บข้อมูลตามนโยบายของวิทยาลัยก่อนเปิดใช้จริง
- บัญชี Google Sheets ต้องจำกัดการแชร์เฉพาะเจ้าหน้าที่ที่มีหน้าที่; ไม่เปิด Sheet สาธารณะ
- ความปลอดภัยของ **รหัสเชิญ** ขึ้นกับการแจกจ่ายอย่างเป็นส่วนตัว (รหัสเป็น bearer token และไม่ใช่การยืนยันตัวตนหลายปัจจัย)
- ต้องเปิด Cloudflare WAF/Rate Limiting หรือ Turnstile ตามความเหมาะสมก่อนเปิดรับตอบจากภายนอกจำนวนมาก
- ระบบผู้ดูแลใช้รหัสผ่านเดียวตามที่ตั้งค่า ไม่ใช่ระบบจัดการสิทธิ์หลายบัญชีหรือ SSO หากต้องใช้หลายคนควรเสริม OAuth/roles และ audit log ก่อนใช้จริง
- ไม่มีระบบส่งอีเมลเชิญอัตโนมัติ, ไม่เชื่อมบัญชีธนาคาร, ไม่มีจ่ายเงินในระบบ, ไม่มีการเปิดบัญชี Krungthai Campus อัตโนมัติ
- ก่อนส่ง CSV ให้ธนาคาร ต้องยืนยันช่องทางปลอดภัย รูปแบบไฟล์ เวอร์ชันแม่แบบ และข้อตกลงการส่งข้อมูลกับผู้ประสานงานธนาคารอีกครั้ง
- **อย่าส่งไฟล์ ZIP ที่มี `.local/` หรือ `private/` หลังติดตั้งให้ผู้อื่น** เพราะอาจมีความลับในเครื่องของคุณ

## โครงสร้างไฟล์

```text
nyc-krungthai-campus-collector/
  install.sh                  # ตัวติดตั้ง Git Bash แบบ resume-safe
  README.md
  schema.json                 # หัวคอลัมน์ที่สกัดจาก Excel (ไม่มีรายชื่อ)
  site/                       # หน้าแบบสำรวจ / Admin / ตัวอ่าน XLSX
  worker/                     # Cloudflare API Gateway
  apps-script/                # Google Apps Script ที่ยังไม่มี Secret
  templates/                  # Excel แม่แบบเปล่า
  tests/                      # ทดสอบ API/Workflow ด้วยข้อมูลสังเคราะห์
  private/                    # สร้างหลังรัน, ไม่ถูกอัปโหลด GitHub
  .local/                     # สร้างหลังรัน, ไม่ถูกอัปโหลด GitHub
```
